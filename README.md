# Zen Odonto — Clínica Dental y Facial

Sitio web oficial y portal interactivo para **Zen Odonto** en **Plaza Costera 125, Acapulco, Guerrero**.

## 🌟 Características
- **4 Secciones Integrales**: Inicio / Filosofía Zen, Tratamientos & Especialidades, Casos Clínicos & Tecnología, y Diagnóstico Virtual & Citas.
- **Comparador Antes / Después Interactivo**: Control deslizante en tiempo real con casos reales de la clínica.
- **Cotizador de Tratamientos**: Estimador transparente de costos con integración directa a WhatsApp.
- **Diagnóstico de Sonrisa (Smile Quiz)**: Test interactivo de 3 pasos con recomendación clínica automática.
- **Sistema de Citas con Calendario**: Generador de archivos `.ics` y enlace formateado a WhatsApp (`744 506 0571`).
- **Modo Relajación Zen**: Sintetizador Web Audio API a 432 Hz para pacientes con ansiedad dental.
- **Despliegue en Vercel**: Compatible de forma nativa con `vercel.json` y URLs limpias.

## 🚀 Despliegue en Vercel
1. Conecta tu repositorio de GitHub `meldnmyrz/zen-odonto` en Vercel.
2. Framework Preset: `Other`.
3. Root Directory: `./`.
4. Clic en **Deploy**.
